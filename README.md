# مدّ — خريطة المد والجزر

تطبيق ويب تفاعلي يربط **الخريطة** بـ**المدّ**: يرسم نموذج الارتفاع الرقمي العالمي (SRTM/ETOPO)
ويقارنه بمستوى سطح البحر المحسوب من ثوابت المد، فـ**تظهر الجزر والسباخ والمِدود مع كل مدّ، وتختفي
مع الجزر** — تماماً كما يحدث على الساحل الحقيقي.

> كل شيء مجاني ومفتوح المصدر: MapLibre GL JS، بلاطات OpenFreeMap، بلاطات الارتفاع AWS Terrain Tiles،
> وتنبؤات NOAA CO-OPS الرسمية. **لا حاجة لأي مفتاح API أو اشتراك.**

---

## ما الذي يفعله التطبيق؟

| الميزة | الوصف |
|---|---|
| **خريطة مريّدة بالمدّ** | طبقة WebGL مخصّصة تقارن ارتفاع الأرض Digital Elevation Model بمستوى سطح البحر: ما دون المد = ماء، وما فوقه = يابسة. |
| **الجزر تظهر وتختفي** | عند مدّ عالٍ تختفي الجزر المنخفضة والسباخ، وعند مدّ منخفض تظهر. |
| **بيانات مدّ حقيقية** | تنبؤات NOAA الرسمية مباشرة من المتصفح (CORS مفتوح)، مع نموذج محلّي احتياطي من ثوابت harmonic مُشتقّة من تلك التنبؤات. |
| **منحنى المد** | مخطط ٤٨ ساعة يعرض المدّ العالي والمنخفض ولحظة الفجر، مع قابلية التقديم والتأخير. |
| **شريط زمني حيّ** | تشغيل/إيقاف، سرعة مضاعفة، وزر "الآن". |
| **أداة إضافة جزر** | انقر على الخريطة لإضافة جزيرة بارتفاع ونصف قطر محدّدين، فترى هل تُغمرها المياه الآن. |
| **عربية/إنجليزية** | واجهة RTL كاملة بالعربية مع تبديل فوري للغة، وأرقام عربية-هندية. |
| **شريط بحث مثل خرائط Google** | بحث فوري في محطات المدّ المحلية **و** في الأماكن عبر Nominatim، مع طيران ناعم إلى النتيجة. |
| **تحكّم مثل خرائط Google** | تكبير/تصغير + بوصلة + ملء الشاشة + مقياس، سحب بالزر الأيمن للتدوير وCtrl+سحب للإمالة. |
| **مبدّل طبقة المدّ** | زر واحد يبدّل بين **الخريطة الأساسية** (شكل خرائط Google) و**طبقة المدّ** (الأرض الرقمية التي تظهر فيها الجزر وتختفي). |
| **نمط liberty** | نمط OpenFreeMap الأقرب إلى خرائط Google (طرق، مبانٍ، تسميات). |

## ⚠️ إذا ظهرت شاشة فارغة بدل الخريطة

السبب في الغالب أنك **فتحت `index.html` مباشرة** (بروتوكول `file://`). المتصفحات تمنع تحميل وحدات
JavaScript من نظام الملفات، فيفشل التطبيق كلياً. الحل: شغّله عبر **خادم HTTP**:

```bash
cd tide-atlas/app
npm install
npm run dev        # ثم افتح: http://localhost:5173
```

أو استخدم المشغّلات الجاهزة: `./start.sh` (لينكس/ماك) و`start.bat` (ويندوز) — يفعلان التثبيت والبناء
والخدمة على `http://localhost:4173`.

أسباب أخرى محتملة: انقطاع الإنترنت (البلاطات تُجلب من CDN) أو متصفح بلا WebGL 2. التطبيق الآن
**لا يتعطّل** في هذه الحالات: يتحول تلقائياً إلى خريطة CARTO البديلة، ويعرض في اللوحة حالة كل مصدر
(`OpenFreeMap · DEM ✓ (12)`) فتنعرف على ما ينقصك بالضبط. استخدم `npm run doctor` لتحديد المصدر
المحجوب من جهازك مباشرة.

## التشغيل

```bash
cd app
npm install
npm run dev        # خادم تطوير على http://localhost:5173
```

ولنسخة الإنتاج:

```bash
cd app
npm run build      # ينتج dist/
npm run preview    # يخدم dist/ على http://localhost:4173
```

> `npm run build` ينسخ عامل MapLibre (`maplibre-gl-worker.mjs`) إلى `public/` تلقائياً — بدونه
> لا يعمل محرك الخريطة في المتصفح.

### خرائط Google؟

التطبيق مبني على MapLibre_GL JSInteraction بنفس مبادئ خرائط Google:

| في خرائط Google | في التطبيق |
|---|---|
| شريط بحث في الأعلى | `#search-input` — بحث محطات + جغرافيا (Nominatim) |
| أزرار التكبير والبوصلة | `NavigationControl` + `FullscreenControl` أسفل اليمين |
| سحب بالزر الأيمن للتدوير | مفعّل افتراضياً في MapLibre |
| خريطة/قمر صناعي | زر **«طبقة المدّ»**: يُبدّل بين الأرض الرقمية والخريطة الأساسية |

### تشخيص الشبكة (عند ظهور شاشة فارغة)

```bash
cd app
npm run doctor
```

يفحص التطبيق كل المصادر الخارجية (نمط الخريطة، البلاطات، الخطوط، خريطة CARTO البديلة، بلاطات
الارتفاع، وواجهة NOAA) ويخبرك **أيّها يحجبه جدارك الناري**:

```
✅  نمط الخريطة (OpenFreeMap)    200 — 192ms
❌  الارتفاع (AWS Terrain Tiles)  TypeError: fetch failed
```

راجع الجدول الذي يميّز بين «مصدر متاح» و«مصدر محجوب» لتحديد المشكلة بدقة.

### الاختبار الآلي

```bash
cd app
npm run preview &                  # يجب أن يكون الخادم يعمل
npm run verify                     # 11 فحصاً في Chromium حقيقي
```

يفحص الفحص: ظهور الخريطة، تعبئة قائمة المحطات، قراءة منسوب الماء، رسم منحنى المد، وجود ماء ويابسة
في الصورة، تأثّر الساحل بتغيير مبالغة المد، تحرّك الشريط الزمني، أداة الجزر، تبديل اللغة، وخلوّ
الصفحة من أخطاء الـconsole.

## البيانات ومصادرها

### ١. الارتفاع (DEM)
[AWS Terrain Tiles](https://registry.opendata.aws/terrain-tiles/) — ترميز *terrarium*:
`elevation = R·256 + G + B/256 − 32768`. يُفكّ الترميز على المعالج ويُرفع كنسيج `R16F` (نصف فاصلة
عائمة) ليُرشَّح بسلاسة، ثم تقارن الـfragment shader قيمة الارتفاع بمستوى المدّ.

### ٢. المدّ
* **مباشر:** [NOAA CO-OPS](https://tidesandcurrents.noaa.gov/) — `product=predictions` ساعياً،
  بوحدة `datum=MSL`. التطبيق يقرأه مباشرة من المتصفح (الرؤوس `Access-Control-Allow-Origin: *`).
* **احتياطي:** ثوابت harmonic لكل محطة في `stations.json`، مُشتقّة بملاءقة أقل المربعات على تنبؤات
  NOAA الرسمية (2024–2025) والتحقّق على 2026. الخطأ الأقصى **وسيطه ١٣ سم** وأسوأه ٢٧ سم.
* الصيغة: `h(T) = offset + Σ aᵢ·cos(ωᵢ·T − gᵢ)` حيث `T` = الساعات منذ 1900-01-01T00:00Z.

> ملاحظة منهجية: الثوابت التي تنشرها NOAA في `harcon.json` تختلف في الطور عن ثوابت محرّك التنبؤ
> الرسمي (خطأ يصل إلى ~٥٠ سم)، لذلك اشتُقّت الثوابت المستخدمة هنا من التنبؤات نفسها بدل نسخها.

### ٣. الخريطة الأساسية
[OpenFreeMap](https://openfreemap.org/) — نمط `positron` متجهي، بلا مفتاح. طبقة DEM تُدرَج قبل
طبقات التسميات، فتبقى أسماء المدن ظاهرة فوق التضاريس المُحوَّلة بالمدّ.

### ٤. حدود النموذج
* مستوى سطح البحر في DEM مربوط بـEGM2008، بينما تنبؤات NOAA مربوطة بـMSL المحلي — الفرق أقل من
  ~٥٠ سم في معظم المواقع، ويوجد **مزلاج "إزاحة مستوى البحر"** في اللوحة للتعديل اليدوي.
* البيانات المتاحة من NOAA تغطي سواحل，平时نفسها والمحيط الهادئ والبحر الكاريبي وأمريكا الوسطى
  والجنوبية. لدول الخليج والبحر الأحمر والمتوسط لم تتوفّر بيانات ساعية بعدُ (خادم UHSLC محجوب من بيئة
  البناء)، لذلك تعمل هذه المناطق بالنموذج المحلي أو بتبديل المصدر.
* DEM الدقيق (SRTM) لا يميّز بوضوح بين المدّ والجزر في البحر على بُعد يتجاوز ~٣٠ كم من الساحل.

## التخصيص السريع

| تريد… | عدّل |
|---|---|
| قيمة ابتدائية للمد | `app/src/main.ts` → `state.exaggeration`, `state.bias` |
| المحطة الابتدائية | `app/src/main.ts` → `state.station` (أو `?station=9414290` في الرابط) |
| ألوان الماء/اليابسة | `app/src/map/dem-layer.ts` → الثابتو `FRAG` |
| مصدر الخريطة | `app/src/main.ts` → `STYLE_URL` |
| محطات جديدة | أضف `id` إلى `PICK` في `tools/fetch_harcon.py` ثم أعد تشغيل الخطّ |
